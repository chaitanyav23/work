
  Detailed Script Audit

  1. Preprocessing Logic
   * Normalization: Strictly followed EBU R128 (loudnorm) with -20 LUFS target. This is critical for NeMo speaker embeddings which are
     sensitive to gain drift.
   * VAD: Used Pyannote 3.1 via pyannote/voice-activity-detection. The script step2_vad_grounding.py applies a 0.15s merge-gap to
     prevent fragmentation of syllables.

  2. Inference Logic
   * ASR (step4_whisperx.py): Explicitly disabled condition_on_previous_text to prevent error propagation across VAD boundaries. Word
     alignment used the whisperx.align engine with language forced to "en".
   * Diarization (step5_msdd.py): Configured with oracle_vad=True which bypasses NeMo's internal MarbleNet and uses the grounding from
     Step 2. This is the "Hardened" configuration. It uses a multiscale approach with titanet_large embeddings.

  3. Fusion Logic (step6_fusion.py)
   * Assignment: Uses temporal intersection. For a word with interval [tₛ, tₑ], it calculates duration( [tₛ, tₑ] ∩ [Tₛ, Tₑ]ᵢ) for all
     MSDD turns i. The speaker with the largest overlap wins.
   * Timeline Generation: Formats seconds into HH:MM:SS and maps raw MSDD labels (speaker_0, etc.) to friendly Speaker_N labels.

  4. Evaluation Logic
   * VAD (step8_vad_eval.py): Frame-based comparison at 10ms resolution.
   * ASR (step9_asr_eval.py): Standard jiwer WER after full normalization (lower-case, no punctuation).
   * Diarization (step10_diar_eval.py): Uses pyannote.metrics.diarization.DiarizationErrorRate. It performs optimal speaker mapping
     (Hungarian algorithm) to find the best match between GT and System labels.
   * Attribution (step11_attribution_eval.py): Word-level accuracy check. Uses greedy mapping to link System speaker IDs to Ground Truth
     speaker IDs.
   * Conversational (step12_13_conversational_eval.py): Computes cpWER by concatenating text per speaker and finding the best
     permutation match.

  Hyperparameters Used
   * VAD Merge Gap: 0.15s
   * Whisper Model: large-v3
   * Alignment Model: Wav2Vec2 Base (default)
   * MSDD Max Speakers: 10
   * MSDD Sigmoid Threshold: 0.7
   * Fusion Tolerance: 0.5s
   * Fusion Segment Gap: 2.0s
